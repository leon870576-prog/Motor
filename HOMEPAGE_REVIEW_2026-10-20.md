# Главная страница «Лесозаводска»

Выпуск `2026-10-20-homepage-r1`, основа `61580cdd876bc78cf2566e2b14c3df937afcef2a`.

## Поведение

Название раздела «Новости сайта» заменено на «Новости» в меню, главной, самом разделе, динамическом заголовке и административном списке заголовков. Прежние подписи из сохранённых настроек нормализуются при выводе; пользовательские сообщения и файлы данных массово не заменяются. Пользовательский шаблон главной сохраняется; точная подпись ссылки «Новости сайта» в нём также выводится как «Новости».

На главной перед каталогом разделов появились шесть блоков: новости, фотографии, темы форума, объявления, мини-чат и гостевая. По умолчанию по три последних записи, для объявлений — до четырёх записей, выбранных администрацией. Пока объявления не выбраны, блок сообщает об отсутствии подборки и не подставляет случайные записи. Последние записи сортируются по времени; для тем используется дата создания темы. Заголовки и фотографии ведут в соответствующие разделы; комментарии новостей и фото используют существующие обсуждения и их актуальные счётчики. Краткие тексты безопасно выводятся без активного HTML и BBCode-вложений. Баллы, авторитет и содержание разделов не меняются.

Администраторы с ролями 101/102 управляют страницей `mpanel/home-settings.php`: количество 0–20 (0 скрывает блок), режим последних/старых/выбранных, уникальный порядок шести блоков, порядок и удаление элементов подборки. Выбор выполняется через список с поиском по названию, тексту и автору, по 20 записей на страницу. Добавление сразу сохраняет выбор и включает ручной режим. В подборке можно хранить до 20 элементов независимо от текущего лимита вывода. Удаление из подборки не удаляет оригинал. Формы работают без JavaScript.

## Хранение и защита

`local/home-settings.json` создаётся только при сохранении, включён в штатный ZIP-бэкап. До первого сохранения используются значения по умолчанию. Изменения сериализуются постоянным `home-settings.lock`, файл заменяется через временный файл и атомарный rename. Каждое сохранение получает новую случайную ревизию; устаревшие и ABA-формы отклоняются. Дублирующее добавление не повторяет запись. Функция записи дополнительно проверяет актуальную авторизацию, роль и блокировку аккаунта. POST, CSRF и Origin обязательны. GET/HEAD новых функций не записывают подборки или исходные записи; обычные счётчики посещений сайта сохраняют прежнее поведение.

Пути источников фиксированы и строятся только из проверенных идентификаторов каталогов. Выбранные ключи используются только для сопоставления, не как файловые пути. Символьные ссылки в настройках, lock-файле, источниках и их дочерних каталогах отклоняются. Размер настроек ограничен 64 КиБ, отдельного источника — 16 МиБ. Повреждённые настройки закрывают ленту с понятным сообщением, без возврата к случайной подборке. Источники читаются с shared lock, без очистки или изменения истории.

Главная и список выбора исключают скрытые фотографии даже для администрации, отсутствующие изображения, просроченные объявления, некорректные и будущие даты/ID. Удалённая выбранная запись не заменяется другой. Числовые ID дополняются временем создания, поэтому обычное повторное использование номера не подменяет подборку. У современных сообщений мини-чата используется UUID; у старых сообщений и гостевой — хеш строки. После редактирования такой старой записи её потребуется выбрать повторно. IP, браузер, служебные ответы и приватные поля из строк сообщений не выводятся.

Старый общий GET-фильтр пропускал только латиницу и не позволял русский поиск. Добавлено узкое исключение только для `q` на `mpanel/home-settings.php`: строка UTF-8 до 480 байт без управляющих символов, затем до 120 символов в контроллере и экранирование при выводе. Остальные параметры и маршруты сохраняют прежние ограничения.
