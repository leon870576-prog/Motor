Проверка безопасности выпуска 2026-10-15-smile-picker-r1

Проверены новые PHP/JavaScript-компоненты выбора смайлов, подключённые поля ввода, вывод данных, права на административный набор и связанные обработчики отправки. Проверки выполнялись на изолированной копии, временных аккаунтах и локальных HTML-снимках форм; пользовательские записи опубликованного сайта не использовались для тестовых отправок.

| Проверка | Результат |
| --- | --- |
| XSS в панели | Каталог передаётся через JSON_HEX_TAG/AMP/APOS/QUOT. Текст создаётся через textContent, вставка — через setRangeText. Нет innerHTML, eval, внешнего HTML или записей в хранилище браузера. |
| Источники изображений | Разрешены только адреса того же сайта с путём к GIF из images/smiles или images/smiles2. Путь проверяется после декодирования; схемы javascript и чужие домены отклоняются. |
| Поддельная отправка (CSRF) | Закрыты обнаруженные пропуски в чате, объявлениях, загрузке фото/комментариях галереи, пирамиде и объяснении бана. Требуются POST и токен формы, сравнение hash_equals. |
| Токен сеанса | Старая генерация из 6 символов заменена на 32 случайных байта (64 hex-символа) через random_bytes. Старые короткие токены обновляются при следующем запросе. |
| Валидация | Отсутствующие, неверные и массивные токены отклоняются с 403; массив вместо текстового сообщения — с 400. Записи при отказах не меняются. |
| Права | Административный набор не передаётся обычному участнику/гостю. В полях, которые поддерживают только общие коды, этот набор не предлагается. Закрытые административные формы не получают панель. |
| Сохранённый вредоносный текст | Попытки вставить HTML, закрывающий textarea, обработчик onerror и script сохраняются/показываются как текст. В браузере ошибок JavaScript и неожиданных диалогов не выявлено. |
| Непреднамеренная отправка | Все кнопки имеют type=button. Enter в поиске не отправляет форму. Выбор смайла не создаёт сетевых записей; проверено счётчиком POST. |
| Файлы и регрессии | Прежние проверки загрузок, доступа, MIME, лимитов, редактирования, удаления и резервной копии пройдены: 147 запросов. Данные local не включены в новый кодовый архив. |

Функциональные и защитные проверки: 150 запросов; 28 вариантов страниц. В Chromium 153 проверены 35 мобильных/альбомных раскладок и touch-события. Синтаксис: 178 PHP-файлов и JavaScript. Отчёты находятся в checks/picker-backend-results.json и checks/picker-browser-results.json.

Граница проверки: это проверка изменённых и связанных участков, а не полный аудит всего старого Motor. В существующей системе входа остаётся устаревшая схема md5(md5(password)) (input.php, includes/header.php); функция «запомнить меня» использует обратимое преобразование. Перевод паролей на современное хеширование и замена долгоживущих cookie требуют отдельной совместимой миграции. В этом выпуске они не изменялись. Физические Android/iPhone не тестировались. Гарантия полного отсутствия уязвимостей не заявляется.
