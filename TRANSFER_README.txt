ПРОДОЛЖЕНИЕ РАБОТЫ
Использовать эту версию целиком, а не только один из старых tar.gz.
Для сборки локальной копии из deployment/:
  mkdir -p site-build
  tar -xzf motor-source.tar.gz -C site-build
  tar -xzf motor-code.tar.gz -C site-build
  sh apply-code-update.sh site-build
Скрипт проверяет контрольные суммы исходников и всех аватарок.
Dockerfile выполняет эти шаги автоматически. Проверки npm test используют
PHP 8.4 WebAssembly. Браузерным проверкам нужен Playwright и Chromium;
путь к установленному Chromium задаётся MOTOR_BROWSER_EXECUTABLE.

ОБНОВЛЕНИЕ УЖЕ РАБОТАЮЩЕГО САЙТА
Сохранить резервную копию и существующий каталог local или /data/local.
Не заменять существующие настройки, профили, загруженные фотографии и
пользовательские аватары содержимым начальной базы. Файлы site/ не содержат
пользовательские данные. Использовать имеющуюся схему Docker-развёртывания
с постоянным диском и миграциями из deployment/.
