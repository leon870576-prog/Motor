# Проверка информаторов — 18 октября 2026

Основа: актуальная версия Motor после увеличения проверочного кода. Исходный motor21.zip и пользовательские данные не заменялись.

## Что проверено и исправлено

| Информатор | Результат |
|---|---|
| Сообщения пользователя в мини-чате | Реальная отправка даёт +1; ответ Насти не входит в личный счётчик. Повтор отправки с тем же идентификатором и отклонённые запросы не дают прибавки. |
| Сообщения форума, гостевой и комментарии | Проверены реальные отправки в каждой категории. Прибавление к профилю теперь читает актуальные значения под блокировкой. |
| Анкета и список жителей | Список больше не показывает устаревшие значения из кэша. Рейтинг по баллам строится по актуальным профилям. |
| Общий счётчик мини-чата, гостевой, админ-чата | Показывает число сохранённых записей; очистка и удаление сразу отражаются в информаторе. Пустые строки не считаются. |
| Форум | Исправлено повторение числа тем в строке «Записей в форуме». Общие числа и информаторы разделов вычисляются по темам и сообщениям, а не по устаревшим служебным значениям. |
| Комментарии новостей и галереи | Удалённые записи, комментарии отсутствующих новостей и отсутствующих фотографий не завышают итог. Галерея учитывает права видимости. |
| Объявления | В счётчик входят действующие объявления; истёкшие исключаются даже до очередной очистки раздела. |
| Зарегистрированные, администрация, баны, ожидающие подтверждения | Числа берутся из профилей; завершившийся по времени бан не считается действующим. |
| Приватные сообщения | Доставка увеличивает уведомление, отклонённая отправка — нет. Получатель видит уведомление; открытие входящих снимает прочитанное количество, не обнуляя более позднее увеличение. |
| Онлайн | Разные аккаунты с общим IP сохраняются отдельно, повторные записи одного аккаунта объединяются, старые записи исключаются. Фоновое обновление чата поддерживает присутствие без добавления хитов. |
| Дни рождения и новички | Вычисляются по профилям и текущей дате; прежний кэш по номеру дня больше не скрывает новых пользователей и не переносит старые значения на следующий месяц. |
| Посещения, таблицы и GIF-графики | Исправлены смена часа/дня после перерыва, совпадающие номера дней в разных месяцах, устаревшие строки истории и отсутствие текущего периода на графике. Таблицы и графики используют одни данные за 24 часовых интервала и 31 календарный день. |
| Рейтинги авторитета, денег и времени на сайте | Читают актуальные профили/банк/данные посещений. Старый кэш больше не подменяет текущие значения. |
| Голосования | Исправлено предупреждение PHP 8.4 при суммировании пустого поля результата. |
| Чёрные списки и служебные количества | Подсчёт непустых записей; проверены зарегистрированные, баны IP, логины, e-mail и сумма голосов. |

Личные числа сообщений — накопленный вклад пользователя. Число возле раздела — сохранённая история. Поэтому после удаления старой переписки эти два числа закономерно отличаются. Исторические личные значения не пересчитывались по обрезанной истории: утраченную переписку нельзя достоверно восстановить таким способом.

«Посещения по IP» сохраняют прежнюю модель движка: новый визит после отсутствия IP в десятиминутном окне. Это не число уникальных людей. Статистика сжатия остаётся оценкой HTML, без изображений, видео и других ресурсов.

## Проверки

- `checks/informers.mjs`: 48 реальных HTTP-запросов в изолированной PHP 8.4-среде и отдельные проверки данных, границ периодов, повторов и неверных идентификаторов.
- Общий `npm test`: обязательная регрессия всех существующих разделов, синтаксиса и защитных сценариев. Результаты сохраняются в `checks/*results.json`.
- `checks/informers-native.php`: сборочная проверка шестью одновременно запущенными PHP-процессами. Проверяет сохранение 240 увеличений профиля, общей статистики и хитов. Не использует рабочие данные.

## Безопасность и границы

Новые счётчики не принимают произвольные пути из запроса. Идентификаторы разделов, тем, новостей и профилей проверяются до чтения файлов; для выдачи чисел используются целочисленные значения. Чтение статистики не исправляет и не удаляет пользовательские записи. Изменения профиля блокируются на весь цикл чтения и записи; уведомления и вклад увеличиваются относительно последнего сохранённого значения. Существующие проверки POST, CSRF, авторизации и прав сохранены.

Встроенные разделы загрузок и библиотеки отсутствуют в этой поставке: их старые агрегаты сохранены, функциональность отсутствующих модулей не объявляется проверенной. Внешние сторонние информаторы не входят в эту проверку. Прежний формат пароля/remember-cookie сохранён по отдельному указанию владельца; ранее описанный риск остаётся открытым. Полное отсутствие уязвимостей не заявляется.
