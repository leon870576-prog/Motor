# Портал «Лесозаводск»

Выпуск `2026-10-20-lesozavodsk-r1`. Портал переименован по указанию владельца: Лесозаводск, Приморский край, Россия.

В общей шапке всех 12 тем установлены название города, регион и герб. Значок вкладки использует тот же герб. Обновлены приветствие, заголовки страниц, стандартное описание и ключевые слова, RSS-подпись, старые упоминания названия в репликах Насти и пример в настройках водяного знака. Кнопка пользователя по-прежнему открывает «Моё меню»; после входа открывается личная страница. Внутренние ID тем и пути `lesika_*` не переименованы, чтобы сохранить выбор пользователей и старые ссылки.

Герб получен с [официального сайта муниципального округа](https://mo-lgo.ru/okrug/simvolika.php), файл `https://mo-lgo.ru/images/coats/user/coat.png`. Исходные PNG-байты 59×70 встроены в локальный SVG без перерисовки, изменения цветов, обрезки и внешних зависимостей. SHA-256 и происхождение зафиксированы в `BRAND_ASSET_SOURCES.json`. SVG содержит только название и встроенное изображение; скриптов, обработчиков событий, foreignObject и внешних ссылок нет. В интерфейсе герб масштабируется с `object-fit:contain`, исходное соотношение сторон сохраняется. Портал не объявляется официальным сайтом администрации.

## Существующие настройки

`includes/portal-brand.php` преобразует прежнее название и исходные демонстрационные метаданные. Пользовательские описания, не содержащие прежнего названия, сохраняются. Старые стандартные URL логотипа обновляются с учётом адреса сайта. Обработка в общем заголовке не записывает данные по GET; свежий установщик сохраняет уже новое название и логотип.

При запуске Railway перед Apache выполняется `migrate-branding.php`. Миграция касается только `local/config.dat` и `local/datalocal/config.dat`. Исходные файлы сохраняются вне веб-каталога в `/data/motor-backups/2026-10-20-lesozavodsk-r1/`, проверяются размер/структура, символьные ссылки и прежние резервные копии. Сохранение выполняется через временный файл и rename; повторная миграция не меняет файлы. Вызов сериализуется отдельной блокировкой. Это операция до запуска веб-сервера, а не миграция для одновременного выполнения с редактированием настроек в админке.

Аккаунты, комментарии, фотографии, новости, баллы, авторитет, кошельки, игровые состояния и пользовательские настройки оформления не изменяются. Содержимое старых сообщений и другие пользовательские тексты не заменяется поиском по всему хранилищу. В комплекте для новой установки изменён только исходный шаблон настроек; действующие данные в архив не включаются.
