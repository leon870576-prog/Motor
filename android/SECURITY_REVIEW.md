# Проверка Android-клиента, 23 октября 2026

Изменён только новый каталог android. Приложение не создаёт собственных аккаунтов и не меняет серверную схему авторизации, CSRF, права и данные сайта.

## Проверяемые границы

- Один точный HTTPS origin для встроенной навигации и передачи credentials. Схема HTTP, другой порт, userinfo, подменный поддомен, управляющие символы, backslash, file/content/javascript/intent не считаются внутренними адресами.
- Ссылки наружу открываются отдельным приложением только после действия пользователя. JS-to-native bridge отсутствует, произвольные Android intents не принимаются, manifest не принимает внешние deep links.
- Cleartext и mixed content запрещены, сертификаты проверяются системой, SSL-ошибка всегда отменяет запрос. Safe Browsing включён. WebView debugging отключён даже в тестовом APK.
- Нет разрешений на камеру, микрофон, местоположение, контакты или весь накопитель. Выбор файла использует системный документ-пикер, результат ограничен content URI; запросы WebView на дополнительные разрешения отклоняются.
- Скачивание ограничено 128 МиБ, четырьмя попытками перехода, таймаутами и исходным origin на каждом шаге. Cookies/HTTP-авторизация не передаются внешнему домену. Проверяется длина ответа, неполный файл удаляется при доступности операции удаления у провайдера документов.
- Для «Поделиться» и браузера query очищается по списку идентификаторов контента, SID/пароли/CSRF/fragment не передаются.
- Секреты, HTML страниц и cookies не логируются, authHeader живёт только в памяти. Android backup отключён; в saved state сохраняется очищенный URL. Стандартные HTTP-auth данные WebView очищаются по явному сбросу входа.
- POST не переотправляется автоматически; на reload формы есть подтверждение. Ошибка сети предлагает открыть GET-страницу.

## Автоматические проверки

Успешно выполнена чистая сборка `clean testDebugUnitTest lintDebug assembleDebug bundleRelease` (98 задач). `UrlPolicyTest`: 4 группы, 0 ошибок; покрыты доверенный origin, схема, порт, поддомен, userinfo, управляющие символы, внешние intents и исключение секретов из ссылки. Android lint: `No issues found` (0 ошибок, 0 предупреждений). Подпись итогового APK проверена `apksigner verify`, схема v2, RSA 2048. Manifest подтверждает minSdk 26 / targetSdk 36 и только INTERNET/ACCESS_NETWORK_STATE. Все 10 нативных ссылок соответствуют файлам собранного последнего сайта.

Современный жест «Назад» обработан через платформенный OnBackInvokedDispatcher на API33+, старый override оставлен для API26–32. Подавление GestureBackNavigation ограничено этим старым override, поскольку lint предлагает AndroidX даже при уже подключённом платформенном callback. Остальные проверки не отключены. Gradle 8.13 сообщает о deprecated API плагина перед переходом на Gradle9; эта сборка закреплена на совместимой версии8.13.

Исходный сайт: полный `npm test` на базе 582d0ba прошёл, включая 447 HTTP-проверок личных страниц, серверные security-тесты и аудит 678 запросов навигации без сломанных ссылок/ошибок статуса/PHP. Наборы выполнялись последовательно в изолированных тестовых данных. Нативные PHP Docker gates отдельно в этой среде не запускались: серверный код не менялся, а публикации Railway приостановлены.

## Диагностика сообщения об ошибке установки 0.1.1

Пользователь сообщил «Ошибка при синтаксическом анализе» при открытии APK до установки. Проверена не только локальная сборка, но и повторно скачанная опубликованная копия: SHA-256 обеих `1557e0ff5b41868c25fdc26f1d374651ae32fa47ce63ad3c895d611ade1d11a7`, размер 34837 байт. ZIP CRC исправны, `apksigner verify --verbose` подтверждает подпись v2, `zipalign -c -v 4` проходит; `resources.arsc` хранится без сжатия с выравниванием 4 байта. Manifest читается, minSdk 26 / targetSdk 36, пакет и сертификат прежние.

Подготовлен отдельный `Leson-Android-install.zip` с `Leson.apk` и инструкцией: сохранить, извлечь, открыть APK из системного файлового менеджера. Байты APK в архиве совпадают с проверенными байтами 0.1.1; бинарный код не изменён и новая версия не заявляется. Это альтернативный способ передачи установщику, а не доказательство установленной первопричины. Без повторной проверки на телефоне нельзя утверждать, что исходная ошибка устранена.

## Границы

### Обновление 0.1.1 — название «Лесон»

Изменены название приложения и тексты интерфейса, имя Gradle-проекта и User-Agent; версия повышена до 0.1.1, versionCode до 2. Повторно выполнены `testDebugUnitTest lintDebug assembleDebug bundleRelease`: 4 теста без ошибок, lint без замечаний. В готовом APK подтверждены label «Лесон», прежний пакет `ru.lesika.portal.preview` и тот же сертификат SHA-256 `694a6b191416be4cfb99998f77ab8edd8d80022cd7627402ce8e36c69ed581c9`. Это позволяет устанавливать обновление поверх версии 0.1.0. Серверный код, сетевые ограничения и разрешения приложения не менялись; серверные тесты повторно не запускались. Установка обновления на физическом телефоне пока не проверена.

Проверка на физическом Android ещё не выполнена. Реальное прохождение тестового HTTP-входа, пользовательского входа, выбора/скачивания файлов, IME, видео и восстановления процесса требуется на устройстве. Проверки URL и lint не заменяют такую проверку.

Push-уведомления и их серверная часть отсутствуют. Дополнительный тестовый доступ сайта сохранён. Публичный выпуск требует отдельной подготовки: постоянный адрес, ключ выпуска, удаление аккаунта/данных, правила и модерация, политика конфиденциальности, декларации магазина. Исторический формат паролей сайта не изменён согласно прежнему указанию владельца; этот клиент не устраняет его риски.
