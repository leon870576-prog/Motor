# Медиа на главной

Выпуск `2026-10-20-home-media-r1`, продолжение текущего main.

Галерея главной содержит только ссылки-фотографии, без заголовка блока, названий, дат, текста и ссылок комментариев. Доступное название сохраняется в alt/aria-label. Предпросмотр по умолчанию 120 × 128 px; администраторы 101/102 меняют ширину и высоту независимо в диапазоне 80–480 px. Фото целиком (`object-fit:contain`), переносятся по доступной ширине. Отключение фото или отсутствие доступных фото убирает блок. Полная галерея и список выбора в админке сохраняют подробности.

Каждый из шести блоков имеет независимые `photos`/`videos` в прежнем `home-settings.json`. Новости и первое сообщение темы форума показывают максимум одно фото и одно видео из существующих вложений; объявления — первое фото через прежний защищённый JPEG-предпросмотр. Галерея/объявления не получают новой функции загрузки видео, мини-чат и гостевая остаются текстовыми. Переключатели не создают отсутствующие медиа. Видео с controls/playsinline/preload=none, без autoplay. При выключении соответствующие теги/URL не выводятся вообще. Количество записей, подборки и их порядок не зависят от числа вложений.

Старые JSON нормализуются только в памяти: отсутствующие переключатели включены, размер 120 × 128. Чтение не записывает настройки. Неверные явно заданные типы, null, массивы и размеры блокируются. Сохранение по POST с прежними CSRF/Origin/правами, stable lock, случайной ревизией, atomic rename и защитой устаревших/ABA-форм. Старые открытые формы после обновления требуют перезагрузки, чтобы не затереть новые параметры. Новые поля включены в прежнее резервное копирование. Профили/контент/исходные архивы не заменяются.

Новый `home-media.php` читает медиа только выбранных для вывода записей. Идентификаторы и типы разрешены по списку, пути локальные и проверяются по каждому компоненту на symlink. JSON ограничен 1 МиБ/12 уровнями/100 вложениями; вывод ограничен одним вложением каждого типа. Проверяются существование файла, изображение, совпадение контекста форума/объявления; повреждённые или отсутствующие вложения пропускаются. Имя файла/тексты экранируются; внешние URL и HTML не используются. Выдача остаётся через прежние авторизуемые attachment.php/resize.php, без прямых ссылок на local.

Проверки:
- `homepage.mjs`: 187 HTTP-запросов, совместимость старого JSON, все 24 сочетания переключателей по блокам, размеры и типы, права/CSRF/Origin, выбор/порядок/версии, backup, XSS, повреждённые/удалённые/неверно привязанные медиа и symlink. Реальная выдача GIF/JPEG/MP4 и Range; счётчики комментариев, баллы, деньги и связанные поля профиля сохраняются при настройке/предпросмотре.
- `homepage-browser.mjs`: 480 раскладок, 8 видов страниц, 12 тем, 320/390/768/1440 px и текст 200%. Границы размеров 80/480, отсутствие переполнения, фото целиком, поля/POST настроек и выбора сохранены.
- `homepage-media-playback.mjs`: реальное воспроизведение MP4 в блоках новости/форума; до запуска видео не запрашивается; при выключении всех медиа нет запросов к их маршрутам.
- Обязательный native homepage gate расширен: 8 одновременных администраторов сохраняют один целый набор размеров/переключателей, 7 получают stale; смешивания параметров, потери профилей/контента и ABA-перезаписи нет.
- Общий npm test завершился с кодом 0: синтаксис 226 PHP/MOT-файлов и 7 JS-файлов, все функциональные наборы, 432 HTTP-проверки безопасности и инвентаризация 1006 файлов. Остальные native Docker gates выполняются до запуска; окончательный результат публикации и healthcheck входит в документацию архива.

Границы: физические устройства и конфигурация будущего хостинга не проверялись. Старый формат паролей сохранён по указанию владельца. Проверки не являются гарантией отсутствия всех возможных уязвимостей.
