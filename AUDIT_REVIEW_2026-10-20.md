# Проверка портала «Лесозаводск», 20 октября 2026 года

Основа: `2f7070dc4e3d8ff8a970d165c1798a0586525344` (Настя: 2000 вариантов). Выпуск исправлений: `2026-10-20-audit-r1`. Проверяется текущая сборка из двух исходных архивов и `code-update`, а не первоначальный motor21.zip. Исходные архивы и рабочие пользовательские данные не заменялись.

## Найдено и исправлено

1. **Старые действия по GET.** Часть действий админки, контактов, игнора и личной почты могла изменять данные по ссылке. Добавлен явный список операций записи; GET и HEAD отклоняются, даже если URL содержит правильный токен. Серверные ссылки заменяются POST-формами с CSRF. Ссылки из пользовательского текста токенов не получают. Внутри уже существующей формы используется кнопка `formaction`, чтобы не создавать вложенные формы. Подтверждения удаления сохранены. Браузерная проверка выявила малый размер новых кнопок; к ним применён общий стиль действий с сенсорным размером 44 px и компактным размером 36 px на ПК в соответствующих темах.
2. **Удаление установщика.** Теперь только POST с CSRF и только главный администратор с ролью 101. У модератора нет права удалить файл установки.
3. **Установка в подкаталоге.** Общая проверка методов теперь определяет маршрут относительно приложения; префикс каталога в `SCRIPT_NAME` не обходит список защищённых действий.
4. **Неверный нулевой результат опроса.** При отсутствии голосов отображается 0 участников. Защита деления на ноль больше не подменяет итоговое число.
5. **Одновременные голоса и новый опрос.** Вопрос, итоги, список участников и административное архивирование используют одну постоянную блокировку. Повторный голос того же пользователя не меняет итог. Версия формы не позволяет отправить старый ответ в заменённый опрос или повторно создать опрос после двойной отправки. Старый формат файлов и прежние итоги сохранены.
6. **Устаревшие списки админки.** Списки администрации, заблокированных и ожидающих регистрации теперь строятся по тем же актуальным профилям, что и счётчики. Пустой или устаревший кэш не скрывает пользователей. Ожидающий пользователь выбирается по логину, а не по изменяемому номеру строки; устаревшая форма отклоняется. Простое открытие списка больше не удаляет старые неподтверждённые аккаунты. Решение «Разрешить/Запретить» выполняется явной отправкой формы.
7. **Некорректные числовые настройки.** Нулевое, отрицательное, текстовое или чрезмерное число записей на странице отклоняется. Допустимо 1–1000; параметры, где 0 означает выключение, сохраняют эту возможность. Существующие некорректные значения пагинации безопасно ограничиваются при чтении без изменения файла. Минимальная сумма кредита не может превышать максимальную.
8. **Потеря настроек при одновременном сохранении.** `change_setting` блокирует весь цикл чтения, изменения и записи. Читатель конфигурации использует shared lock и не видит промежуточное усечённое содержимое.
9. **Ссылки.** Убраны ссылки на неустановленные загрузочный центр и библиотеку в списке онлайн. Добавлена отсутствовавшая страница изменений. Исправлены разделители параметров административных перенаправлений опроса.
10. **Предупреждение PHP.** Открытие комментариев новостей без `id` больше не обращается к отсутствующему ключу массива.
11. **Выпадающие списки компактных тем.** На телефоне список был высотой 40 px при требовании 44 px для сенсорных действий. Высота исправлена; компактные размеры на ПК сохранены. Версия CSS обновлена, чтобы изменения загрузились у прежних посетителей.

### Что именно означает счётчик

| Счётчик | Проверяемое поведение |
|---|---|
| Комментарии в анкете | Накопленный вклад: новости, галерея, личные новости и отзывы; удаление текста не обнуляет прежний вклад |
| Комментарии возле записи | Число существующих видимых комментариев; удаление уменьшает это число |
| Баллы и внутренняя валюта за комментарий | Общая прибавка +1/+1; повтор одной формы личной страницы не начисляет повторно |
| Авторитет | Смена +1 на −1 меняет итог на −2 и переносит один голос между положительными и отрицательными; одинаковый повтор ничего не меняет |
| Чат, форум, гостевая | Личный вклад сохраняется после очистки истории; публичные числа отражают существующие записи; боты не увеличивают вклад пользователя |
| Пользователи и администрация | Актуальные профили; просроченный бан исключается из числа заблокированных |
| Голосование | Ровно один голос участника, 0 при пустом опросе; совпадение результатов и списка участников |
| Посещения и онлайн | Полные даты при смене часа/дня, разные аккаунты за одним IP, отсутствие лишних хитов от фонового опроса чата |

## Границы проверки

Это проверка доступного кода и конкретных воспроизводимых сценариев, а не доказательство отсутствия всех уязвимостей. Сохраняется ранее согласованный владельцем старый формат паролей/remember-cookie; он не приведён к современному password hashing в этой работе. Файловые блокировки защищают от проверенной конкуренции, но запись нескольких файлов не является общей транзакцией с журналом аварийного восстановления. Повреждение диска и откат лишь части `local` требуют согласованной резервной копии.

Браузерные проверки используют Chromium и эмуляцию экранов, а не реальные устройства Safari/Firefox. Отправка настоящих писем, конфигурация произвольного стороннего хостинга и нагрузка большого публичного сайта этим прогоном не подтверждаются. На изолированных тестах почта отключена. Живые пользовательские данные не использовались в качестве тестовых фикстур.
