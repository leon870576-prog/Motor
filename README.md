# WAP-MOTOR 21: тестовая копия

Основа — последняя подтверждённая владельцем сборка wapmotor_php84_footer_clean.zip, объединённая с проверенными исправлениями PHP 8.4 и запуска Railway. Сохранены название «Лесика», очистка демонстрационной рекламы и удаление согласованной строки внизу страниц. Выпуск: 2026-10-15-lesika-themes-r2. Исходники, темы, изображения и начальные каталоги данных находятся в motor-source.tar.gz. Docker распаковывает архив автоматически. Изменения движка перечислены в CHANGES.json. Авторские уведомления и условия сохранены в исходниках (help/LICENSE.html).

## Тестовый адрес и первоначальная настройка

https://motor-testing.up.railway.app

Сайт закрыт отдельным HTTP-паролем. Данные доступа передаются владельцу отдельно и отсутствуют в репозитории. После входа откроется установщик: владелец знакомится с соглашением, создаёт администратора и задаёт HTTPS-адрес сайта. После установки удалите INSTALL.php из админки. При следующем запуске контейнера установщик также удалится автоматически, если профиль администратора уже существует.

## Развёртывание

Railway: проект motor21-test, сервис motor, окружение testing. Источник — main этого репозитория. Используется Dockerfile; настройки healthcheck /_health, таймаута 120 секунд и перезапуска ON_FAILURE заданы в Railway. Устаревший railway.json удалён: Config as Code больше не принимается Railway.

Данные и сессии хранятся на постоянном диске /data. Только одна реплика сервиса. Переменные MOTOR_TEST_USER, MOTOR_TEST_PASSWORD и PORT настроены в Railway. Apache использует только mpm_prefork; конфигурация проверяется apache2ctl -t при сборке и перед запуском. Скрипт инициализации вызывается через CMD, чтобы выполняться на Railway.

Изменения кода через редактор админки не переживают новое развёртывание; обновляйте код в репозитории. Не распаковывайте motor-source.tar.gz вручную в корень репозитория.

## Проверки и ограничения

PHP 8.4 WebAssembly: проверен синтаксис 166 PHP-файлов, создание временного администратора, HTTPS-адрес установки, главная, новости и текст новости, форум, гостевая, галерея, формы регистрации/входа, вход и панель администратора, BB-коды. Тестовые данные сюда не включены.

Готовность реального контейнера контролируется HTTP-проверкой /_health. Главная и установщик требуют HTTP-пароль; каталоги local и includes закрыты для прямого доступа. Работа загрузки файлов на реальном хостинге ещё не проверена.

Почтовая отправка и чтение внешних URL отключены в тестовой конфигурации. Схема паролей пользователей остаётся старой: используйте отдельные тестовые пароли. Код и данные сайта «Лесика» не переносились.

## Обновление существующих данных

migrate.php выполняет миграцию 2026-10-15-footer-clean-v1 один раз. Меняются только старые стандартные значения названия, приветствия, внешнего адреса и логотипа, а также точно совпадающие исходные рекламные файлы. Логин, пароль, адрес сайта и другие изменённые владельцем настройки сохраняются. Перед изменением исходные файлы копируются в /data/motor-backups/2026-10-15-footer-clean-v1. Каталог недоступен через сайт. Метка выполненной миграции находится в /data/.motor-migrations.

Правило выбора исходной версии зафиксировано в AGENTS.md: уточнять сборку у владельца и по умолчанию выбирать последнюю версию с изменениями.

## Тёплые темы Лесики

Перенесены все семь палитр из сайта «Лесика»: Тёплый двор, Городская газета, Городская гостиная, Солнечный город, Вечерний уют, Соседский альбом, Современный уют. Старые каталоги тем удалены из поставки. Выбор: /pages/themes.php, кнопка «Темы» в нижней навигации, личные настройки или основные настройки администратора. Для зарегистрированного пользователя выбор записывается в профиль; для гостя — в сессию и cookie.

Старые темы заменяются при старте через migrate-themes.php; резервные копии в /data/motor-backups/2026-10-15-lesika-themes-v1. Остальные поля профиля и конфигурации сохраняются. Существующая тема night_city переходит в «Вечерний уют», прочие старые темы — в «Тёплый двор». Настроенная пользователем главная страница сохраняется; стандартный список разделов получает карточки Лесики.
