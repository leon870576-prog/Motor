# WAP-MOTOR 21: тестовая копия

Движок WAP-MOTOR 21 из предоставленного motor21.zip, с исправлениями запуска на PHP 8.4. Исходники, темы, изображения и начальные каталоги данных находятся в motor-source.tar.gz. Docker распаковывает архив автоматически. Изменения движка перечислены в CHANGES.json. Авторские уведомления и условия сохранены в исходниках (help/LICENSE.html).

## Тестовый адрес и первоначальная настройка

https://motor-testing.up.railway.app

Сайт закрыт отдельным HTTP-паролем. Данные доступа передаются владельцу отдельно и отсутствуют в репозитории. После входа откроется установщик: владелец знакомится с соглашением, создаёт администратора и задаёт HTTPS-адрес сайта. После установки удалите INSTALL.php из админки. При следующем запуске контейнера установщик также удалится автоматически, если профиль администратора уже существует.

## Развёртывание

Railway: проект motor21-test, сервис motor, окружение testing. Источник — main этого репозитория. Используется Dockerfile; настройки healthcheck /_health, таймаута 120 секунд и перезапуска ON_FAILURE заданы в Railway. Устаревший railway.json удалён: Config as Code больше не принимается Railway.

Данные и сессии хранятся на постоянном диске /data. Только одна реплика сервиса. Переменные MOTOR_TEST_USER, MOTOR_TEST_PASSWORD и PORT настроены в Railway. Apache использует только mpm_prefork; конфигурация проверяется apache2ctl -t при сборке.

Изменения кода через редактор админки не переживают новое развёртывание; обновляйте код в репозитории. Не распаковывайте motor-source.tar.gz вручную в корень репозитория.

## Проверки и ограничения

PHP 8.4 WebAssembly: проверен синтаксис 166 PHP-файлов, создание временного администратора, HTTPS-адрес установки, главная, новости и текст новости, форум, гостевая, галерея, формы регистрации/входа, вход и панель администратора, BB-коды. Тестовые данные сюда не включены.

Готовность реального контейнера контролируется HTTP-проверкой /_health. Главная и установщик требуют HTTP-пароль; каталоги local и includes закрыты для прямого доступа. Работа загрузки файлов на реальном хостинге ещё не проверена.

Почтовая отправка и чтение внешних URL отключены в тестовой конфигурации. Схема паролей пользователей остаётся старой: используйте отдельные тестовые пароли. Код и данные сайта «Лесика» не переносились.
