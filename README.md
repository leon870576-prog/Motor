# WAP-MOTOR 21: тестовая копия

Движок WAP-MOTOR 21 из предоставленного motor21.zip, с исправлениями запуска на PHP 8.4. Исходники, темы, изображения и начальные каталоги данных находятся в motor-source.tar.gz. Docker распаковывает этот архив автоматически. Изменения перечислены в CHANGES.json. Авторские уведомления и условия сохранены в исходниках (help/LICENSE.html).

## Загрузка в GitHub с телефона

1. Распакуйте внешний архив motor-github-upload.zip. Внутри 9 файлов.
2. Откройте https://github.com/leon870576-prog/Motor/upload/main
3. Выберите все 9 файлов и нажмите Commit changes. Они должны находиться в корне репозитория.
4. motor-source.tar.gz оставьте архивом: распаковывать его не нужно.
5. После загрузки сообщите в чате «Загрузил».

## Railway

Подключить этот репозиторий к уже созданному сервису motor в проекте motor21-test, окружение testing. Диск /data и переменные MOTOR_TEST_USER, MOTOR_TEST_PASSWORD, PORT уже настроены отдельно в Railway; секретов в этом репозитории нет. Используются Dockerfile и railway.json.

После успешного запуска: создать HTTPS-домен, проверить /_health.php, защиту паролем, недоступность /local/config.dat и работу установщика. Аккаунт администратора создаётся в установщике. После установки удалить INSTALL.php из админки. При следующем запуске контейнера установщик также удалится автоматически, если профиль администратора уже существует.

## Что проверено

PHP 8.4 WebAssembly: синтаксис 166 PHP-файлов, создание временного администратора, HTTPS-адрес установки, главная, новости и текст новости, форум, гостевая, галерея, формы регистрации/входа, вход и панель администратора, BB-коды. Тестовые данные сюда не включены.

Docker-сборка, Apache, реальный хостинг, загрузка файлов и браузерная работа ещё не проверены. Рабочей интернет-ссылки пока нет.

Почтовая отправка и чтение внешних URL отключены в тестовой конфигурации. Схема паролей пользователей остаётся старой: используйте только отдельные тестовые пароли. Весь сайт, кроме /_health.php, закрыт дополнительным HTTP-паролем. Код и тестовые данные «Лесики» не переносились.

Данные и сессии сохраняются в /data на постоянном диске. Изменения кода через редактор админки не переживают новое развёртывание; обновляйте код в репозитории. Только одна реплика сервиса.
