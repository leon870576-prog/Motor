## Главная страница и её редактор (2026-10-21)

В панели управления есть связанные разделы «Главная страница: блоки и записи» и «Главная страница: шаблон разделов». Пока index.dat — точный старый стандартный файл, сайт и редактор согласованно используют includes/lesika/home.php. Первое сохранение помещает видимый в редакторе актуальный исходник в index.dat. Редактор доступен только назначенному владельцу сайта. Перед заменой проверяется синтаксис PHP и версия файла, исходник сохраняется в защищённый каталог local/home-template-backups. Кнопка «Восстановить стандартный шаблон» возвращает актуальные стандартные карточки и ссылки, сохраняя настройки ленты и записи. Синтаксическая проверка не проверяет смысл произвольного PHP: при ручных правках необходима проверка результата через «Посмотреть главную». Не открывать каталог local по HTTP.
